See \texttt{src/featuremaps/featuremap.py} for the degree-$k$ implementation. The plot below shows hypothesis curves for $k\in\{3,5,10,20\}$.

As $k$ increases, the hypothesis curve fits the training data more tightly. For low $k$ the fit is poor (underfitting), while for high $k$ the curve begins to oscillate in regions with sparse data. Neither extreme gives a good representation of the true underlying sine function.

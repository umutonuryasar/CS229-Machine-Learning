\begin{answer}
From part (a) we have $\int p(y;\eta)(y - a'(\eta))\,dy = 0$. Differentiating both sides w.r.t.\ $\eta$:
\[
0 = \int \frac{\partial}{\partial\eta}\bigl[p(y;\eta)(y-a'(\eta))\bigr]\,dy
  = \int \Bigl[\frac{\partial p}{\partial\eta}(y-a'(\eta)) - p(y;\eta)\,a''(\eta)\Bigr]\,dy.
\]
Using $\dfrac{\partial p}{\partial\eta} = p(y;\eta)(y-a'(\eta))$:
\[
0 = \int p(y;\eta)(y-a'(\eta))^2\,dy - a''(\eta)\underbrace{\int p(y;\eta)\,dy}_{=1}.
\]
Since $\mathbb{E}[Y;\eta] = a'(\eta)$, the integral equals $\mathbb{E}[(Y-\mathbb{E}[Y])^2] = \operatorname{Var}(Y;\eta)$. Therefore:
\[
\operatorname{Var}(Y;\eta) = \frac{\partial^2}{\partial\eta^2}a(\eta). \qquad \blacksquare
\]
\end{answer}

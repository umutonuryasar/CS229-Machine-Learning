\begin{answer}
With independent Laplace priors $\theta_i \sim \mathcal{L}(0,b)$:
$$\log p(\theta) = \sum_i \left(-\log(2b) - \frac{|\theta_i|}{b}\right) = \text{const} - \frac{1}{b}\|\theta\|_1.$$

The MAP objective is:
\begin{align*}
\theta_{\mathrm{MAP}} &= \operatorname*{argmin}_\theta \left[-\log p(\vec{y}|X,\theta) - \log p(\theta)\right]\\
&= \operatorname*{argmin}_\theta \left[\frac{1}{2\sigma^2}\|X\theta - \vec{y}\|_2^2 + \frac{1}{b}\|\theta\|_1\right]\\
&= \operatorname*{argmin}_\theta \left[\|X\theta - \vec{y}\|_2^2 + \frac{2\sigma^2}{b}\|\theta\|_1\right].
\end{align*}

This matches the Lasso loss $J(\theta) = \|X\theta - \vec{y}\|_2^2 + \gamma\|\theta\|_1$ with
$$\boxed{\gamma = \frac{2\sigma^2}{b}.}$$
Therefore, MAP estimation with a zero-mean Laplace prior is equivalent to $L_1$-regularized linear regression, also known as Lasso regression. $\square$
\end{answer}
